# 📈 株価比較ダッシュボード

yfinanceとStreamlitを使った株価データ可視化アプリです。**日本株・米国株対応、通貨変換機能付き！**

## 🆕 新機能

- **日本株対応**: 証券コード + .T で日本株を検索可能（例: 7203.T）
- **通貨変換機能**: USD/JPY間で自動変換し、統一通貨で比較
- **為替レート考慮**: 過去の為替レートを使用した正確な価格変換

## 機能

- 📊 **株価チャート表示**
  - ラインチャートで複数銘柄を比較
  - ローソク足チャートで詳細な値動きを確認
  - 異なる通貨の銘柄を統一通貨で表示

- 💱 **通貨変換** 🆕
  - USD（米ドル）またはJPY（日本円）で表示
  - 過去の為替レートを自動取得して変換
  - 日米株を同じ通貨で比較可能

- 📈 **騰落率比較**
  - 複数銘柄のパフォーマンスを視覚的に比較
  - 開始時点を100として正規化

- 📋 **統計情報**
  - 最高値、最安値、平均値、標準偏差
  - 出来高情報
  - セクター情報
  - 元の通貨情報を表示

- 💾 **データダウンロード**
  - CSV形式でダウンロード可能

## セットアップ

### 1. リポジトリをクローン

```bash
git clone <your-repository-url>
cd stock-dashboard
```

### 2. 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 3. アプリを起動

```bash
streamlit run stock_dashboard.py
```

ブラウザが自動的に開き、アプリが表示されます。

## 使い方

1. サイドバーで銘柄シンボルを入力（カンマ区切り）
2. **表示通貨を選択（USD または JPY）** 🆕
3. 表示期間を選択
4. チャートタイプを選択
5. 「データ取得」ボタンをクリック

### 銘柄シンボルの例

- **米国株**: AAPL, MSFT, GOOGL, AMZN, TSLA
- **日本株**: 7203.T (トヨタ), 6758.T (ソニー), 9984.T (ソフトバンク), 6861.T (キーエンス)
- **日本商社**: 8058.T (三菱商事), 8001.T (伊藤忠), 8031.T (三井物産)
- **インデックス**: ^GSPC (S&P500), ^DJI (ダウ), ^N225 (日経平均)

### 日米株比較の例 🆕

```
銘柄入力: AAPL, MSFT, 7203.T, 6758.T
表示通貨: JPY
```

この設定で、AppleとMicrosoftの米国株、トヨタとソニーの日本株を、すべて円換算で比較できます！

## Streamlit Cloudにデプロイ

### 方法1: GitHub経由（推奨）

1. GitHubリポジトリを作成してコードをpush
2. [Streamlit Cloud](https://streamlit.io/cloud)にアクセス
3. 「New app」をクリック
4. リポジトリ、ブランチ、メインファイル（stock_dashboard.py）を選択
5. 「Deploy」をクリック

### 方法2: 直接アップロード

1. [Streamlit Community Cloud](https://streamlit.io/cloud)でアカウント作成
2. ファイルをアップロードしてデプロイ

## 注意事項

- データはYahoo Financeから取得しており、15-20分程度の遅延があります
- 為替レートも過去データを使用しており、リアルタイムではありません
- 日本株のシンボルは証券コード + .T（例: 7203.T = トヨタ）
- 通貨変換には各日の終値為替レートを使用しています
- このツールは情報提供を目的としており、投資助言ではありません
- 投資判断は自己責任でお願いします
